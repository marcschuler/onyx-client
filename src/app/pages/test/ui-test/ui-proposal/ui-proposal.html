Two problems in today's CSS that every new class would run into. Both are fixes in styles.css and style.ui.css, not new classes.

F1 · global rules win over Tailwind utilities

The element rules (h1 – h4, label, input, textarea, select, a) and most .button-* classes are not in a cascade layer. Unlayered CSS always beats Tailwind's @layer utilities, so a utility on these elements does nothing unless it gets a !.

F2 · .container is also a Tailwind utility
.container

Tailwind v4 ships a container utility: width: 100% plus a max-width per breakpoint. The templates use the class name, so Tailwind generates it and it merges into the box from style.ui.css. At this window width ({{ windowWidth() }}px) the box above gets max-width: {{ containerMaxWidth() }}. The intro page already works around it with min-w-full. Fix: rename it to .card (next section).
